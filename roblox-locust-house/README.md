# 🦗 ДОМ САРАНЧИ: Подкат и Дерзость

Полностью рабочий прототип хоррор-побега для Roblox в духе «Дома саранчи»:
ты просыпаешься в тёмном доме, по нему ходит тварь, надо собрать ключи и свалить через выход.

**Но со своей фишкой** (это то, чего нет в оригинале):

| Фишка | Что делает |
|---|---|
| 🔥 **ДЕРЗОСТЬ (рейджбайт)** | Кнопка `T` — специально палишься и дразнишь монстра. Он звереет: бегает быстрее, видит дальше, перестаёт вестись на приманки. Зато твой **множитель очков** растёт за каждую подколку подряд (до x5). Поймал — весь накопленный банк сгорает. Хочешь много очков — рискуй. |
| 🛷 **ПОДКАТ** | Кнопка `C` — персонаж ужимается и проскальзывает в **низкий лаз** в стене. Монстр туда не пролезет: ему придётся бежать в обход через двери. Это твой главный способ разорвать дистанцию. |
| 🎯 **ПРИМАНКИ** | Кнопка `Q` — бросаешь маленький триггер. Он пищит, монстр идёт на звук и тупит рядом 4.5 секунды. **Но в ЯРОСТИ приманки на него не действуют** — сам себе усложнил. |

Весь дом, монстр и интерфейс **генерируются кодом**. Ничего скачивать и моделить не надо —
закинул скрипты, нажал Play, играешь.

## 🚀 Как запустить

### Вариант А — быстро, руками (10 минут, без доп. программ)

1. Открой Roblox Studio → **New → Baseplate**.
2. В `Explorer` создай эти объекты и скопируй в них код:

| Куда | Что создать | Имя | Файл из этой папки |
|---|---|---|---|
| `ReplicatedStorage` | Folder | `LocustShared` | — |
| ↳ внутри него | ModuleScript | `GameConfig` | `src/shared/GameConfig.lua` |
| ↳ | ModuleScript | `Util` | `src/shared/Util.lua` |
| ↳ | ModuleScript | `Remotes` | `src/shared/Remotes.lua` |
| `ServerScriptService` | Folder | `LocustServer` | — |
| ↳ | **Script** | `Main` | `src/server/Main.server.lua` |
| ↳ | ModuleScript | `MapBuilder` | `src/server/MapBuilder.lua` |
| ↳ | ModuleScript | `MonsterModel` | `src/server/MonsterModel.lua` |
| ↳ | ModuleScript | `MonsterAI` | `src/server/MonsterAI.lua` |
| ↳ | ModuleScript | `RageService` | `src/server/RageService.lua` |
| ↳ | ModuleScript | `BaitService` | `src/server/BaitService.lua` |
| ↳ | ModuleScript | `RoundService` | `src/server/RoundService.lua` |
| `StarterPlayer → StarterPlayerScripts` | Folder | `LocustClient` | — |
| ↳ | **LocalScript** | `Main` | `src/client/Main.client.lua` |
| ↳ | ModuleScript | `Hud` | `src/client/Hud.lua` |
| ↳ | ModuleScript | `MovementController` | `src/client/MovementController.lua` |
| ↳ | ModuleScript | `ActionController` | `src/client/ActionController.lua` |
| ↳ | ModuleScript | `Effects` | `src/client/Effects.lua` |

> Важно: `Main` в `ServerScriptService` — это обычный **Script**, а `Main` в `StarterPlayerScripts` — **LocalScript**. Остальные все — **ModuleScript**.

3. `Home → Game Settings → Avatar → Animation/Rig type` поставь **R15**
   (подкат ужимает персонажа, а это работает только на R15).
4. Жми **Play**. Дом, монстр, ключи и интерфейс появятся сами.

### Вариант Б — по-взрослому, через Rojo

```bash
# ставим Rojo один раз
cargo install rojo   # или скачай с https://rojo.space

cd roblox-locust-house
rojo serve
```
В Studio: плагин Rojo → **Connect**. Все скрипты сами разложатся по местам.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | ходьба |
| `Shift` | бег (жрёт выносливость и **шумит** — монстр слышит) |
| `C` / `Ctrl` | **подкат** — пролезть в лаз, монстр обходит |
| `Q` | бросить **приманку** |
| `T` | **ПОДРАЗНИТЬ** (главная фишка: +ярость монстру, +множитель тебе) |
| `F` | фонарик |
| `E` | подобрать ключ (когда подошёл к тумбе) |

## 🎯 Цель раунда

1. Найти **4 ключа** (жёлтые светящиеся, лежат на тумбах в разных комнатах).
2. Красная дверь на севере откроется и позеленеет.
3. Добежать до зелёной площадки за дверью.
4. Очки = 100 за побег + весь банк дерзости, который ты успел накопить и не потерять.

Поймали → скример, ты умираешь, респавнишься, **банк дерзости сгорает**. Ключи при этом остаются собранными.

## 🧠 Как думает монстр

Простой конечный автомат в `MonsterAI.lua`:

```
Патруль ──слышит шум──> Идёт проверять ──дошёл──> Ищет вокруг ──не нашёл──> Патруль
   │                                                    ▲
   └──────────── УВИДЕЛ ИГРОКА ──> ПОГОНЯ ──потерял──────┘
                                      │
                                      └── дистанция < 4.5 → поймал
```

- **Видит**: конус обзора 110°, 60 студов (в ярости — 95), с проверкой лучом (за ящиком не видит).
- **Слышит**: бег (26 студов), подкат (40), приманку (70), подколку (220 — считай, весь дом).
- **Ходит** через `PathfindingService`. Лазы помечены `PathfindingModifier` с бесконечной стоимостью — поэтому монстр физически не может решить пойти через лаз и всегда бежит в обход.

## ⚙️ Всё настраивается в одном файле

`src/shared/GameConfig.lua` — там все числа с комментариями. Хочешь хардкор:

```lua
GameConfig.Monster.ChaseSpeed = 24     -- быстрее спринта игрока, убежать нельзя
GameConfig.Round.KeysToEscape = 6      -- больше ключей
GameConfig.Rage.SpeedBonus = 0.8       -- в ярости он просто ракета
GameConfig.Slide.HeightScale = 0.42    -- насколько низко приседаешь в подкате
```

## 🔊 Что добавить дальше (звуки, модель монстра)

В коде намеренно нет чужих asset id — подставь свои:

- **Звуки**: создай `Sound` в `Workspace` и играй его в `RoundService:onCatch` (скример),
  в `RageService:taunt` (крик монстра) и в `BaitService` (писк приманки).
- **Нормальная модель монстра**: замени `MonsterModel.build()` на свою модель из Toolbox —
  главное, чтобы внутри были `Humanoid` и `HumanoidRootPart`, остальной код менять не надо.
- **Анимация ходьбы**: добавь `Animator` в `Humanoid` монстра и играй анимацию,
  когда `humanoid.WalkSpeed > 0`.
- **Больше комнат**: правь `buildInterior()` в `MapBuilder.lua` — стены задаются
  парой чисел «от» и «до», а `vent(...)` ставит новый лаз.

## 📦 Публикация

`File → Publish to Roblox As...` → назови игру → в `Game Settings → Permissions` поставь Public.
Игра сразу многопользовательская: ключи общие, дерзость у каждого своя.
