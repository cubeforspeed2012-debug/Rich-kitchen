# 🕯️ HE WILL COME (v2)

Кооп-хоррор до 4 человек. Заброшенная школа, ночь, 5 ключей спрятаны в рюкзаках на партах,
а по коридорам ходит **ОН** — заметит, заорёт на всю школу и побежит.

Вдохновение: «Дом саранчи» (дом, ключи, монстр, прятки) и «Scream and Run» (тёмная школа,
обыск рюкзаков, бег / присед / подкат / фонарь, монстр-патруль с погоней).

## ⚡ Установка за минуту

1. Скачай **`build/HeWillCome.rbxlx`** (кнопка `Download raw file` на странице файла в GitHub).
2. Roblox Studio → `File` → `Open from File...` → найди файл мышкой в «Загрузках», двойной клик.
3. **Play**.

> В редакторе мир пустой — это нормально, всё строится при запуске.
> R15 уже включён в файле места. Если открываешь не через `.rbxlx`, а вставляешь модели —
> поставь `Game Settings → Avatar → R15` сам, иначе присед и подкат не будут ужимать персонажа.

Проверить вдвоём: `Test` → `Clients and Servers` → `2 players` → `Start`.

Если что-то не запустилось, **на экране появится красная плашка с текстом ошибки** — скинь её.
Ещё смотри `View → Output`: сервер пишет `[HE WILL COME] сервер запущен`, клиент — `клиент запущен`.

## 🎮 Управление

| Клавиша | Действие | Шум |
|---|---|---|
| `Shift` | бег (стамины на ~7 сек) | **громко**, слышно за 42 стада |
| `C` | красться (тумблер) | **вообще не слышно** |
| `Shift` + `C` на бегу | подкат — рывок за угол | средне |
| `F` | фонарь | не звук, но **тебя видно за 95 стадов вместо 55** |
| `E` | обыскать рюкзак / спрятаться в шкафчик / поднять напарника | обыск — шумно |
| `T` | **крикнуть** — ОН бросает всё и идёт к тебе | на всю школу |

## 🎯 Как играть

1. Лобби → **Создать комнату** (или **Войти** в чужую). Больше 4 не пустит.
2. Хост → **НАЧАТЬ ИГРУ**. Вас телепортирует в школу, у вас **20 секунд тишины** при свете.
3. Свет тускнеет, ОН просыпается в котельной и начинает патруль.
4. Обыскивай рюкзаки на партах (их 47, ключей 5). **Каждый найденный ключ делает его быстрее.**
5. 5/5 — ворота во дворе открылись. Через холл, главный вход, по асфальту на юг к зелёной площадке.

**Поймал — не убил, а уронил.** 40 секунд лежишь, напарник поднимает за `E` (4 сек).
Если один — сразу вылет. **Крик `T` из лежачего положения** — способ позвать на помощь ценой того,
что ОН придёт первым.

**Шкафчики** (19 штук по школе): прыгнул — он тебя не видит. Но если он **видел, как ты прыгнул** — откроет и вытащит.

## 👁️ Как думает ОН

```
Спит (20 сек) → Патруль ──шум──> Проверяет точку ──дошёл──> Ищет вокруг 6 сек ──> Патруль
                    │                                               ▲
                    └─── УВИДЕЛ (конус 100°, 55 стадов) → ОРЁТ → ПОГОНЯ ──потерял на 3 сек──┘
                                                              │
                                                              └── дистанция < 4 → уронил
```

- Патруль 12, идёт на шум 17, **погоня 25.5** (спринт игрока 24) — по прямой не убежишь,
  надо ломать ему обзор за углом, подкатом и шкафчиком.
- +0.9 к скорости за каждый ключ: с 5 ключами гонится на 30.
- Слышит: бег 42, ходьба 12, подкат 30, обыск рюкзака 36, дверца шкафа 22, крик — всю школу.
- Ходит через `PathfindingService`, лампы рядом с ним мигают — это предупреждение.

## 🗺️ Карта

Школа 256×192 стадов: библиотека, 4 класса, спортзал, столовая, учительская, туалеты,
кладовка, холл, мастерская, котельная, два коридора и двор с забором и деревьями.

Карта — текст. Файл `src/server/MapData.lua` генерируется из `tools/gen_school_map.py`,
где комнаты заданы прямоугольниками, а двери — координатами. Скрипт **проверяет, что каждая
комната, шкафчик, парта и ворота достижимы от спавна**, и падает, если ты замуровал проход.

```
python3 tools/gen_school_map.py        # перерисовать карту
python3 tools/build_roblox_files.py    # пересобрать .rbxlx / .rbxmx
```

Легенда: `#` стена, `W` окно, `.` пол комнаты, `,` коридор, `D` дверной проём, `L` шкафчик,
`B` парта с рюкзаком, `P` спавн, `M` монстр, `F` забор, `X` ворота, `T` дерево, `=` асфальт.

## ⚙️ Настройки — `src/shared/GameConfig.lua`

```lua
GameConfig.Monster.ChaseSpeed = 25.5     -- скорость погони
GameConfig.Monster.SpeedPerKey = 0.9     -- насколько злеет с каждым ключом
GameConfig.Monster.SightRange = 55       -- как далеко видит
GameConfig.Match.KeysRequired = 5
GameConfig.Match.PrepTime = 20           -- тишина до пробуждения
GameConfig.Match.DimLights = 0.28        -- яркость ламп после пробуждения (0 = кромешная тьма)
GameConfig.Rooms.MaxPlayers = 4
```

## 📁 Файлы (если вставляешь руками)

| Куда | Тип | Файлы |
|---|---|---|
| `ReplicatedStorage` → Folder `HWCShared` | ModuleScript | `GameConfig`, `Remotes`, `Util` |
| `ServerScriptService` → Folder `HWCServer` | **Script** `Main` + ModuleScript | `Main.server.lua`, `MapData`, `MapBuilder`, `LobbyBuilder`, `Monster`, `Match`, `Rooms` |
| `StarterPlayer → StarterPlayerScripts` → Folder `HWCClient` | **LocalScript** `Main` + ModuleScript | `Main.client.lua`, `Input`, `Hud`, `LobbyUI`, `Effects` |

Или три модели из `build/`: `HWCShared.rbxmx` → ReplicatedStorage, `HWCServer.rbxmx` → ServerScriptService,
`HWCClient.rbxmx` → StarterPlayerScripts (правый клик → `Insert from File...`).
