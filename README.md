# Rich Kitchen — сайт мебельной компании

Премиальный одностраничный сайт (лендинг) для компании **Rich Kitchen** — мебель на заказ в Ташкенте.
Двуязычный: **русский / узбекский** (переключатель RU/UZ вверху справа).

Сайт статический (HTML + CSS + JS без сборки) — открывается в любом браузере и размещается на любом хостинге.

## 🖼 Как заменить фото на свои

Все изображения лежат в `assets/img/`. Замените файлы **с теми же именами** — и ничего в коде менять не нужно.
Рекомендуемые размеры (соотношение сторон важнее пикселей):

| Файл | Где на сайте | Формат | Рекомендуемый размер |
|------|--------------|--------|----------------------|
| `hero.jpg` | Главный экран | вертикальное 4:5 | 1600×2000 |
| `about.jpg` | Блок «О компании» | вертикальное 4:5 | 1200×1500 |
| `cat-kitchen.jpg` / `cat-wardrobe.jpg` / `cat-living.jpg` / `cat-bath.jpg` | Категории | вертикальное 4:5 | 1000×1200 |
| `project-1.jpg` … `project-6.jpg` | Портфолио | горизонтальное 4:3 | 1200×900 |
| `cta.jpg` | Тёмный блок «Бесплатная консультация» | горизонтальное | 1600×900 |

> Совет: делайте фото в тёплой гамме (дерево, свет, натуральные материалы) — так они лягут в общий стиль.

## 📞 Как изменить контакты

Контакты сейчас — **заглушки**. Замените их в двух местах: `index.html` и, для телефона, при желании в `js` не требуется.
Найдите и замените по всему файлу `index.html`:

| Что | Текущее значение (заглушка) | Где встречается |
|-----|------------------------------|-----------------|
| Телефон | `+998 (90) 000-00-00` и `tel:+998900000000` | верхняя панель, кнопки, контакты, футер |
| Instagram | `instagram.com/richkitchen.uz` | верхняя панель, контакты, футер |
| Telegram | `t.me/richkitchen` | контакты, футер |
| WhatsApp | `wa.me/998900000000` | контакты |
| E-mail | `hello@richkitchen.uz` | контакты, футер |
| Адрес шоурума | «Ташкент, Мирзо-Улугбекский р-н» | блок «Контакты» (RU и UZ) |
| Часы работы | «Пн–Сб · 10:00–19:00» | верхняя панель и «Контакты» |

Быстрый способ: открыть `index.html` в редакторе и через «Найти и заменить» поменять номер телефона `+998900000000` сразу везде.

## ✉️ Как подключить форму заявки

Сейчас форма показывает сообщение «Заявка отправлена!», но **никуда не отправляет данные**.
Чтобы заявки приходили вам, в `js/main.js` найдите комментарий:

```js
// NOTE: подключите отправку на бэкенд / Telegram-бот / e-mail здесь.
```

Варианты подключения (от простого к сложному):
1. **Telegram-бот** — самый быстрый для Узбекистана. Отправлять `fetch` на `https://api.telegram.org/bot<TOKEN>/sendMessage`.
2. **Готовый сервис форм** — Formspree, Getform, Web3Forms (просто указать `action` у формы).
3. **Свой бэкенд** — отправлять `POST` с полями `name`, `phone`, `type`, `msg`.

## 🌐 Языки (RU / UZ)

Каждый текст хранится в атрибутах `data-ru` и `data-uz` прямо в `index.html`.
Чтобы изменить текст — правьте оба атрибута. Переключение работает автоматически, выбранный язык запоминается в браузере.

## 🔤 Шрифты

Подключены с Google Fonts (нужен интернет у посетителя):
- **Cormorant Garamond** — заголовки (элегантный serif)
- **Inter** — основной текст

Если хостинг без внешних запросов — можно скачать шрифты и подключить локально; при отсутствии шрифтов сайт аккуратно использует системные (Georgia / system-ui).

## 🚀 Как опубликовать

Это статический сайт — подойдёт любой из вариантов:
- **Netlify / Vercel** — перетащить папку в веб-интерфейс (drag & drop).
- **GitHub Pages** — включить Pages для репозитория.
- **Обычный хостинг** — залить файлы по FTP в корень сайта.

Точка входа — `index.html`.
