# Rich Kitchen — сайт мебельной компании

Премиальный одностраничный сайт (лендинг) для компании **Rich Kitchen** — мебель на заказ в Ташкенте.
Двуязычный: **русский / узбекский** (переключатель RU/UZ вверху справа).

Сайт статический (HTML + CSS + JS без сборки) — открывается в любом браузере и размещается на любом хостинге.

## 🖼 Как заменить фото на свои

Все изображения лежат в `assets/img/`. Замените файлы **с теми же именами** — и ничего в коде менять не нужно.
Рекомендуемые размеры (соотношение сторон важнее пикселей):

| Файл | Где на сайте | Формат | Рекомендуемый размер |
|------|--------------|--------|----------------------|
| `hero.jpg` | Главный экран | вертикальное 4:5 | 1600×2000 |
| `about.jpg` | Блок «О компании» | вертикальное 4:5 | 1200×1500 |
| `cat-kitchen.jpg` / `cat-wardrobe.jpg` / `cat-living.jpg` / `cat-bath.jpg` | Категории | вертикальное 4:5 | 1000×1200 |
| `project-1.jpg` … `project-6.jpg` | Портфолио | горизонтальное 4:3 | 1200×900 |
| `cta.jpg` | Тёмный блок «Бесплатная консультация» | горизонтальное | 1600×900 |

> Совет: делайте фото в тёплой гамме (дерево, свет, натуральные материалы) — так они лягут в общий стиль.

## ✉️ Форма заявки → Supabase → Telegram

Заявки уходят на защищённый сервер (**Supabase Edge Function** `lead`), который:
1. проверяет данные и отсекает спам (honeypot + лимит 3 заявки в минуту с одного IP);
2. сохраняет заявку в таблицу `leads` — ничего не теряется;
3. пересылает её в Telegram.

**Токен бота хранится в секретах Supabase, а не в коде сайта** — украсть его со страницы нельзя.

### Настройка секретов (один раз)
В панели Supabase → **Project Settings → Edge Functions → Secrets** добавьте:

| Имя | Значение |
|-----|----------|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `TELEGRAM_CHAT_ID` | ваш Telegram ID |

Заявки видны в Supabase → **Table Editor → leads**, даже если Telegram недоступен.

### Если меняете адрес сайта
Разрешённые домены заданы в функции (`ALLOWED_ORIGINS`). При переезде на свой домен
добавьте его туда и передеплойте функцию.

## 🤖 Бот-помощник для клиентов

Функция `bot` делает Telegram-бота дружелюбным собеседником:

- **`/start`** — здоровается (по-русски или по-узбекски, в зависимости от языка клиента)
  и показывает кнопки: сайт, звонок, Instagram, шоурум на карте.
- **Любое сообщение** — вежливо благодарит клиента и **пересылает его сообщение владельцу**
  вместе с именем, username и ID, чтобы можно было ответить напрямую.
- Чат владельца не трогается — уведомления о заявках туда приходят без автоответов.

### Подключение (один раз)
1. Добавьте в Supabase ещё один секрет: `TELEGRAM_WEBHOOK_SECRET` (любая длинная случайная строка).
2. Один раз откройте в браузере ссылку, подставив свой токен и тот же секрет:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<ПРОЕКТ>.supabase.co/functions/v1/bot&secret_token=<СЕКРЕТ>
```

Ответ `{"ok":true}` означает, что бот подключён. Секрет защищает вебхук: без него
посторонние не смогут слать боту поддельные сообщения.

## 🧊 3D-модель кухни (Blender)

П-образная кухня 3.6 × 4.4 м собирается скриптом — вся геометрия строится
по размерам, а не лепится вручную.

```
tools/blender/kitchen.py       # генератор модели
assets/3d/rich-kitchen.blend   # готовый файл, открывается в Blender
assets/3d/renders/*.png        # визуализации (4 камеры)
```

**Открыть модель:** Blender → File → Open → `assets/3d/rich-kitchen.blend`.
Объекты разложены по коллекциям (помещение, нижние модули, столешница,
верхние модули, пеналы, техника, свет, камеры) — лишнее можно скрыть одним щелчком.

**Пересобрать после правок:**

```bash
blender --background --python tools/blender/kitchen.py -- --render
```

Ключи: `--render` (рендер камер), `--samples N` (качество), `--res W H`,
`--cameras overview,corner,sink,hob`, `--glb` (экспорт для 3D-просмотра на сайте),
`--no-save`.

**Что менять в скрипте** — блок «Габариты и раскладка» в начале файла:

| Что | Переменная |
|-----|------------|
| Размеры помещения | `ROOM_W`, `ROOM_D`, `ROOM_H` |
| Глубина и высота модулей | `BASE_D`, `CARCASS_H`, `WALL_D`, `WALL_BOTTOM`, `TALL_H` |
| Состав фронтов | `BACK_RUN`, `LEFT_TALL`, `LEFT_BASE`, `RIGHT_RUN` |
| Окно, проём | `WIN_X0`/`WIN_X1`/`WIN_Z0`/`WIN_Z1`, `DOOR_X0`/`DOOR_X1` |
| Цвета материалов | `PALETTE` (HEX, взяты из `css/main.css`) |

Ряды описаны списками `(ширина, тип модуля)`; типы — `door_l`, `door_r`,
`drawers2`, `drawers3`, `sink`, `hob`, `fridge`, `oven`. Достаточно поменять
список — фасады, ручки, столешница и фартук пересчитаются сами.
